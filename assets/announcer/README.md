Положи сюда свои аудиофайлы announcer-серий.

Поддерживаемые имена файлов:

- `double-kill.mp3`
- `triple-kill.mp3`
- `quadra-kill.mp3`
- `rampage.mp3`
- `dominating.mp3`
- `unstoppable.mp3`
- `monster-kill.mp3`
- `godlike.mp3`
- `immortal.mp3`
- `legendary.mp3`

Как это работает:

- при серии побед `x2` проигрывается `double-kill.mp3`
- при серии побед `x3` проигрывается `triple-kill.mp3`
- и так далее
- для `x10+` используется `legendary.mp3`

Требования:

- формат лучше `mp3`
- короткий клип 1-3 секунды
- названия файлов должны совпадать символ в символ

Если файла нет, игра просто не проиграет announcer-аудио для этого уровня.
