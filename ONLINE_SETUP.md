# Онлайн-режим

Онлайн-игра сделана через Supabase и работает без собственного сервера.

## 1. Создай бесплатный проект Supabase

1. Открой `https://supabase.com/dashboard/projects`
2. Создай новый project
3. Открой `SQL Editor`
4. Выполни содержимое файла `supabase-setup.sql`

Если проект Supabase у тебя уже был создан раньше и онлайн уже работал:

1. Открой `SQL Editor`
2. Выполни содержимое файла `supabase-score-migration.sql`

Это добавит общий счёт для онлайн-комнат.

## 2. Включи ключи в игре

Открой файл `config.js` и вставь свои данные:

```js
window.TIC_TAC_TOE_CONFIG = {
  supabaseUrl: "https://YOUR_PROJECT.supabase.co",
  supabaseAnonKey: "YOUR_SUPABASE_ANON_KEY"
};
```

Где взять значения:
- `supabaseUrl`: `Project Settings` -> `API` -> `Project URL`
- `supabaseAnonKey`: `Project Settings` -> `API` -> `anon public`

## 3. Как играть

1. Один игрок нажимает `Играть онлайн` -> `Создать комнату`
2. Копирует ссылку или код комнаты
3. Второй игрок открывает ссылку или вводит код
4. Игра начинается автоматически

## 4. Бесплатный деплой

Самый удобный вариант:
- залить проект на Cloudflare Pages
- или на Netlify / GitHub Pages

Так как это обычный статический сайт, сервер для хостинга не нужен.

## 5. Что важно знать

- Онлайн сейчас сделан для режима `3x3`
- Локальные режимы и игра против бота остались как были
- RLS здесь максимально простой, этого достаточно для дружеской игры, демо и портфолио
